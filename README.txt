# Undangan Khitanan Ahnaf Nabiiha Shabil

## Cara menjalankan
Buka `index.html` di browser.

## Sebelum dipublikasikan
1. Ganti nomor WhatsApp pada bagian `const nomor="6281234567890";`
2. Jika sudah punya koordinat/lokasi Google Maps yang tepat, ganti link Google Maps pada tombol lokasi.
3. Upload folder ini ke GitHub lalu deploy ke Vercel.

Foto sudah disertakan sebagai `ahnaf.png` dan `keluarga.png`.
